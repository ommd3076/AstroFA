BoardUI free components vendored from the official registry. All listed sources are MIT licensed.

- Button: https://www.boardui.com/r/button.json
- Button Group: https://www.boardui.com/r/button-group.json
- Chip: https://www.boardui.com/r/chip.json
- Table: https://www.boardui.com/r/table.json
- Utilities: https://github.com/BoardUI/boardui/tree/main/utils

Registry path aliases were rewritten to local relative imports. Theme tokens are scoped to `.boardui-surface` and mapped to Costellar's graphite/periwinkle palette. BoardUI's React Aria Table runtime is supplied by `react-aria-components`.
