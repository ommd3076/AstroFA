The [SmoothUI Scrubber](https://smoothui.dev/docs/components/scrubber) is
distributed under the MIT license in this directory. Its source is available
from the [SmoothUI registry](https://smoothui.dev/r/scrubber.json).

Costellar uses the scrubber to set the planetarium’s field of view. The
upstream class-name helper import was adapted to the local Board UI helper.
The [Design Bookmark Motion collection](https://designbookmark.com/motion)
references this component and also informed the atlas navigation motion.
